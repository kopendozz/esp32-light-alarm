# Hardware

Currently the alarm is built on breadboard wiring around an off-the-shelf
ESP32-S3-DevKitC-1 (see the [top-level README](../README.md#hardware) for the
wiring table). A dedicated PCB is planned.

Once designed, this directory will hold:

| Path (planned) | Contents |
| --- | --- |
| `hardware/schematic/` | KiCad schematic (`.kicad_sch`) |
| `hardware/pcb/` | KiCad PCB layout (`.kicad_pcb`) |
| `hardware/bom/` | Bill of materials export |
| `hardware/gerbers/` | Fabrication-ready Gerber exports |

Not yet present — this file is a placeholder until the KiCad design work
starts.
